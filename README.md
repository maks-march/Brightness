# BrightnessControl

Небольшое Android-приложение на Kotlin и Jetpack Compose для расширенного управления яркостью.

## Что умеет приложение

- задавать системную яркость от 0% до 100% с переводом в диапазон Android 0..255;
- использовать диапазон −100%…−1% для затемнения через Accessibility Overlay, при этом системная яркость устанавливается в 0%;
- работать поверх других приложений через foreground service;
- восстанавливаться после перезагрузки через `BOOT_COMPLETED`;
- проверять обновления и устанавливать APK из GitHub;
- сохранять выбранную тему и параметры яркости в локальных настройках.

Публичный API Android не позволяет физически превысить максимум дисплея, поэтому 100% — аппаратный максимум. Значение 0% и кнопка «Сбросить» устанавливают системную яркость в 0% и выключают затемнение. Для отрицательного диапазона требуется разрешение специальных возможностей, а для изменения системной яркости — разрешение «изменение настроек системы».

## Быстрый запуск

1. Откройте каталог в Android Studio.
2. Укажите Android SDK 35 и JDK 17 (AGP 8.7 требует Java 17).
3. Проверьте ссылки GitHub и e-mail в `app/build.gradle.kts`.
4. Соберите `./gradlew assembleDebug` или `./gradlew assembleRelease`.
5. При первом запуске выдайте приложению разрешения из раздела «Доступ».

В демо-проекте лежит development keystore `keystore/brightness-release.jks` с паролем `brightness-dev`. Перед публикацией замените его и значения в `gradle.properties`. Debug и release намеренно используют один и тот же keystore, чтобы APK-обновления не конфликтовали по подписи.

## Публикация обновления

Linux/macOS/Git Bash/WSL:

```bash
./release.sh 1.1.0
```

Windows PowerShell или CMD:

```powershell
.\release.ps1 1.1.0
```

или:

```bat
release.bat 1.1.0
```

Скрипт увеличит `versionCode`, соберёт release APK, положит его в `apk/BrightnessControl.apk`, обновит `version.json` и проверит подпись. Если сборка завершится ошибкой, `app/build.gradle.kts` и `version.json` автоматически восстановятся. Скрипт не меняет системную Java: он автоматически ищет совместимый JDK 17 в `%USERPROFILE%\.jdks` или `~/.jdks` и использует его только для этой сборки. После успешной сборки отправьте `apk/BrightnessControl.apk` и `version.json` в репозиторий, затем создайте commit.
