# BrightnessControl

Небольшое Android-приложение на Kotlin и Jetpack Compose для расширенного управления яркостью.

## Что умеет приложение

- затемнять экран ниже системного уровня через прозрачный overlay;
- поднимать системную яркость от сохранённой базовой точки до аппаратного максимума;
- работать поверх других приложений через foreground service;
- восстанавливаться после перезагрузки через `BOOT_COMPLETED`;
- проверять обновления и устанавливать APK из GitHub;
- сохранять выбранную тему и фон в локальных настройках.

Android не предоставляет публичного API для физического увеличения яркости выше аппаратного максимума. Поэтому положительная часть шкалы доводит системную яркость до 100%, а отрицательная использует overlay. Для затемнения и фоновой работы необходимо разрешение «поверх других приложений»; для изменения системной яркости — разрешение «изменение настроек системы».

## Быстрый запуск

1. Откройте каталог в Android Studio.
2. Укажите Android SDK 35 и JDK 17 (AGP 8.7 требует Java 17).
3. Проверьте ссылки GitHub и e-mail в `app/build.gradle.kts`.
4. Соберите `./gradlew assembleDebug` или `./gradlew assembleRelease`.
5. При первом запуске выдайте приложению разрешения из раздела «Доступ».

В демо-проекте лежит development keystore `keystore/brightness-release.jks` с паролем `brightness-dev`. Перед публикацией замените его и значения в `gradle.properties`. Debug и release намеренно используют один и тот же keystore, чтобы APK-обновления не конфликтовали по подписи.

## Публикация обновления

```bash
./release.sh 1.1.0
```

Скрипт увеличит `versionCode`, соберёт release APK, положит его в `apk/BrightnessControl.apk`, обновит `version.json` и проверит подпись. После этого отправьте `apk/BrightnessControl.apk` и `version.json` в репозиторий, затем создайте commit.
